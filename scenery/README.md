# Scenery

The horizon silhouettes a theme can choose with `backdrop.horizon`: `forest` (normandy-treeline), `mountains`,
`floating` (pandora-isles), `waves`, `city`, `seafloor`, `dunes`, `snowpines`, `hills`. Shell:B draws the chosen one
along the bottom of the page in `backdrop.horizonColor`; `scripts/validate.py` draws it into each theme's preview the
same way. They are copies of Shell:B's own files, so a new silhouette has to land in Shell:B first.
